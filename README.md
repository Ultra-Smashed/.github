# Ultra Smashed

Offene Claude-Skills für konkrete Arbeit. Auf Deutsch, mit klarer Grenze, was der Skill tut und was du selbst freigibst.

Christopher Thanisch, Ultra Smashed GmbH, Köln.

## Installieren

In Claude Code:

```
/plugin marketplace add Ultra-Smashed/<repo>
```

In der Claude-App den Repo-Link in einen neuen Chat legen und „Installier diesen Skill für mich.“

## Skills

- [linkedin-agent-skill](https://github.com/Ultra-Smashed/linkedin-agent-skill) schreibt, prüft und plant LinkedIn-Posts.
- [instagram-agent-skill](https://github.com/Ultra-Smashed/instagram-agent-skill) macht Reel, Caption, Kommentare und Wochenplan.
- [remove-slop-skill](https://github.com/Ultra-Smashed/remove-slop-skill) nimmt KI-Floskeln aus deutschen und englischen Texten.
- [reflexion-skill](https://github.com/Ultra-Smashed/reflexion-skill) bespricht eine Aufgabe nach und schreibt die Lektion fest.
- [lexware-skill](https://github.com/Ultra-Smashed/lexware-skill) und [sevdesk-skill](https://github.com/Ultra-Smashed/sevdesk-skill) erledigen Buchhaltung im jeweiligen Programm.
- [daytrader-skill](https://github.com/Ultra-Smashed/daytrader-skill) ist ein Satz Skills fürs Daytrading. Paper zuerst, keine Anlageberatung.

Fürs Büro liegen außerdem Skills zu Vertrieb, Marketing, Finanzen, Kundenservice, Strategie, Prozessen, Verträgen und Mentoring.
